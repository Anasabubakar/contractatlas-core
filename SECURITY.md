# Security

ContractAtlas is a read-only reporting tool. It holds no keys and signs nothing. Its results are observations, not a security assessment.

Report a vulnerability (for example a way to make the checker report `match` when the live code differs, or to leak an RPC URL into output) through GitHub's private vulnerability reporting for this repository (Security tab, "Report a vulnerability"). Please do not open a public issue for it.

Out of scope: the fixture contract (`fixtures/upgradeable-fixture`) is a test subject, not a product, and intentionally has a single admin.
